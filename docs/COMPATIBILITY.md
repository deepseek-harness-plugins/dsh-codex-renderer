# DSH 0.2.1-rc.2 兼容修复

验证日期：2026-10-17。插件版本：**0.3.2**。宿主：官方 Desktop 安装包附带的 **DSH 0.2.1-rc.2** CLI，使用隔离 Web profile 与 Chrome、本地模拟模型验证。

## 修复行为

展开思考正文时，表格、Mermaid 与音视频控件继续工作。

## 原因与处理

原先的装饰方式复制原生组件并注册新的优先级入口，却没有保留原生入口声明的子插槽。新版 DSH 通过这份声明提供 `renderSlot`，思考正文和模型标签因此出现 `renderSlot is not a function`，出错的入口还会被宿主停止渲染。

现在只包装原生入口的组件，保留入口身份、注入缓存、store、语言和子插槽所有权；用低优先级通知条目刷新已挂载界面。停用时先移除自己的包装层，再释放已有的通知条目，不在失效的插件上下文中创建新注册。多个插件可以按任意顺序退出，保留其他插件与原生组件。

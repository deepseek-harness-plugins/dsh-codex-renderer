# Codex 音视频控件对齐记录

以本机 Codex 桌面端的音视频组件布局和控件样式为依据，在 DSH 0.2.0-rc.2 宿主中验证。所有数值是 CSS 像素，截图使用 2 倍显示比例。

表格、表格预览和 Mermaid 图表保持 0.1.4 的实现。

| 控件 | Codex 的布局与数值 | 插件实现 |
| --- | --- | --- |
| 音频卡片 | 最大宽度 512px、8px 圆角 | 文件附件卡片，主题颜色跟随 DSH |
| 文件行 | 40px 图标、6px 内边距、10px 内容间距 | 文件名与格式分两行，右侧播放和选项 |
| 音频时间轴 | 20px 原生 range、8px 上下和 12px 左右内边距 | 独立进度行，显示当前时间与总时长 |
| 视频框 | 6px 圆角、独立下方操作条 | 内嵌视频加自定义控制区域 |
| 视频操作条 | 40px 高度、8px 左右内边距、28px 按钮 | 播放、进度、音量、选项和全屏 |
| 视频时间轴 | 2px 轨道、16px 滑块、圆角与阴影 | 指针悬停、拖动定位、键盘操作 |
| 提示框 | 16px 圆角、左右 12px、上下 5px、200ms 延迟 | 独立提示层，点击和滚动时收起 |
| 播放选项 | 文件操作、0.25–2 倍速、画中画 | 菜单跟随触发按钮，全屏时进入全屏容器 |

图标由本插件绘制，颜色使用 DSH 的主题变量。视频使用自定义控件；音频时间轴与 Codex 一样使用浏览器的 range 控件。

## 验证

`npm run check` 在隔离的真实 DSH 宿主中验证音视频播放、定位、倍速、音量、静音、全屏内菜单、HTTP 媒体与本地媒体，以及表格、图表、插件启停和批注兼容性。

`assets/audio.png` 和 `assets/video.png` 由真实宿主生成，README 与截图随功能一起更新。
